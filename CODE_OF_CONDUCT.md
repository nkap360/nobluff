# Code of conduct

This project is a place to argue about evidence, not about people.

- Disagree with claims, code and wording; never with someone's competence or identity.
- No harassment, insults, sexualised content or personal attacks, in any channel linked to this project.
- Assume good faith once; ask for a reproduction if you doubt a report.

Maintainers may edit or remove contributions that break these rules and may block repeat offenders. Report a problem privately through [GitHub's private reporting](https://github.com/provenwork/nobluff/security/advisories/new) or by contacting the maintainers of the [provenwork](https://github.com/provenwork) organisation.
