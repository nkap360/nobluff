# Security policy

NoBluff is a set of instructions (`SKILL.md` files) plus a small standard-library example. It runs no service and collects no data.

The realistic risk is a skill that pushes an agent toward an unsafe action, such as running a destructive command "to gather evidence". If you find wording that does that, report it privately: [open a security advisory](https://github.com/provenwork/nobluff/security/advisories/new). Please do not open a public issue for it.

You will get an answer within seven days. Fixes ship as a patch release and are listed in [CHANGELOG.md](CHANGELOG.md).
